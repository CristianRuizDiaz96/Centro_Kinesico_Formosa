# Centro Kinésico Formosa — propuesta de sitio

Versión de prueba armada para mostrar cómo quedaría la página del centro.
No es el sitio oficial. Algunos datos están puestos por suposición y hay que confirmarlos.

HTML, CSS y JavaScript sin frameworks.

## Dónde se cambia cada cosa

- **Horarios:** en `js/script.js`, en la lista `HORARIOS`, y también en el texto de `index.html`.
- **Colores y tipografía:** en `css/estilos.css`, arriba de todo (`:root`).
- **Teléfono y WhatsApp:** en `index.html`, en los dos botones del bloque `estado`.
- **Ubicación del mapa:** en `index.html`, las coordenadas del `iframe` y del botón "Cómo llegar".

## Datos a confirmar

Están marcados en `index.html` con comentarios `CONFIRMAR`:

- Días y horarios de atención.
- Obras sociales con las que trabajan.
- Nombres, títulos y matrículas de los profesionales.
- La dirección exacta.
- Los servicios y cómo describirlos.
